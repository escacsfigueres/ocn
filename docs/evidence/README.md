
# Evidence gathered for the chronicle layer

Raw answers from the source libraries, one file per head, written by
`tools/ask_treatise_sources.py`. These are **evidence to read, not claims**:
an answer here has not been reviewed, graded, or applied to anything.

The useful ones are often the negatives. A library that answers "not in
these sources" has told you where not to spend an afternoon, which is why
every question ends by asking for that answer rather than a plausible one.
