# Fonts

Every face here is licensed under the **SIL Open Font License 1.1**, whose full
text is in `OFL-1.1.txt`. The licence requires that it travel with the fonts,
and until 2026-08-05 this directory shipped six of them without it. Each file
also carries its own copyright notice in its embedded name table.

| file | family | used for |
|---|---|---|
| `uDIN1451Mittelschrift.ttf` | u_DIN 1451 Mittelschrift | display type, in the explorer and the monograph. Regular only: the identity has no bold weight, which is a decision and not an omission |
| `spectral-400.woff2`, `-400i`, `-600` | Spectral | reading text |
| `plexmono-400.woff2`, `-500`, `-600` | IBM Plex Mono | identifiers, move lists, figures |

Reserved Font Names apply: if you modify one of these files, rename it, as
clause 3 of the licence requires.
